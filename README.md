# ![AudioNav Compass Icon](./app/src/main/play_store_512.png) AudioNav Compass

AudioNav Compass is an audio compass app for Android devices.

## Installation

It is recommended to install AudioNav Compass using [Obtainium](https://obtainium.imranr.dev/) and point it at the AudioNav Compass GitHub repository. If you use Obtainium you can get app update notifications.

For those who want to get the APK directly and install manually, please find the APK files on the [releases page](https://github.com/mwhapples/AudioNavCompass/releases).
